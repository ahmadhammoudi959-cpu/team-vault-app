# الخزنة — خزنة كلمات السر للفريق

برنامج ويب لحفظ بيانات دخول حسابات العملاء (إنستجرام، فيسبوك، حسابات الإعلانات، السيستمات…) مع بحث فوري باسم العميل.
مبني بتشفير «صفر معرفة» (zero-knowledge): السيرفر وقاعدة البيانات لا يريان أي كلمة سر أبدًا.

## طبقات الحماية

| # | الطبقة | ماذا تمنع |
|---|--------|-----------|
| 1 | **باب مخفي**: الموقع يرد `Not Found` على كل شيء ما لم يُفتح «رابط الدخول السري» على الجهاز | الماسحات والهاكرز لا يجدون حتى صفحة دخول |
| 2 | **موافقة على كل جهاز جديد** من المدير قبل فتح الخزنة | سرقة كلمة السر ورمز التحقق وحدها لا تكفي |
| 3 | **كلمة سر رئيسية لا تغادر الجهاز**: يُشتق منها مفتاحان في المتصفح (PBKDF2-SHA256 × 1,000,000 ثم HKDF)، ويصل للسيرفر مفتاح دخول مشتق فقط | لا شيء يُسرق من السيرفر يكشف كلمة السر |
| 4 | **تحقق بخطوتين إجباري** (Google / Microsoft Authenticator) مع منع إعادة استخدام الرمز | كلمة السر المسروقة وحدها لا تفتح |
| 5 | **قفل الحساب** بعد 5 محاولات خاطئة (15 دقيقة تتضاعف حتى 24 ساعة) + حدود معدل للطلبات | التخمين |
| 6 | **تشفير طرف-لطرف**: كل حساب يُشفَّر في المتصفح بـ AES-256-GCM بمفتاح الخزنة، والمفتاح يُوزَّع لكل عضو بتشفير ECDH P-384 | قاعدة البيانات لا ترى إلا بيانات مشفرة |
| 7 | **تشفير ثانٍ مستقل على السيرفر** (AES-256-GCM بمفتاح موجود فقط في متغيرات Render) | تسريب قاعدة البيانات وحدها عديم القيمة |
| 8 | **قاعدة البيانات لا تحتوي إلا بيانات مشفرة مرتين**، والاتصال بها مشفر TLS إجباريًا بكلمة سر عشوائية طويلة موجودة فقط في إعدادات Render (قاعدة Neon المجانية لا تسمح بحجب عناوين IP؛ عند الترقية لخطة مدفوعة على Neon أو Render يمكن قفلها على الشبكة الخاصة فقط) | حتى من يصل للقاعدة نفسها لا يرى إلا رموزًا بلا معنى |
| 9 | **تحصين المتصفح**: CSP صارم + Trusted Types + HSTS + منع الإطارات + صفر سكربتات خارجية | حقن الأكواد (XSS) والتصيد عبر الإطارات |
| 10 | **جلسات قصيرة**: كوكيز `__Host-` آمنة، قفل تلقائي بعد 10 دقائق، مسح الحافظة بعد 30 ثانية، كلمة السر مخفية حتى تُطلب | جهاز مفتوح أو حافظة منسية |
| 11 | **سجل نشاط لا يُحذف**: كل دخول وكل عرض/نسخ لكلمة سر يُسجَّل (قاعدة البيانات نفسها ترفض تعديل السجل) | تسريب من الداخل بدون أثر |
| 12 | **تغيير مفتاح الخزنة عند إزالة عضو**: تُعاد تشفير كل الحسابات بمفتاح جديد | العضو المُزال لا ينفعه ما احتفظ به |
| 13 | **لا نشر تلقائي** (`autoDeployTrigger: off`): أي تعديل على GitHub لا يصل للموقع إلا بضغطة Deploy من Render | اختراق GitHub وحده لا يغيّر الموقع |

## أول تشغيل (مرة واحدة)

1. بعد النشر على Render افتح الخدمة ← **Logs**، وستجد سطرًا فيه `FIRST-TIME SETUP` ورابطًا ينتهي بـ `/setup/...` (يظهر في كل تشغيل إلى أن يُنشأ أول مدير، ثم يتوقف الرابط عن العمل).
2. افتح الرابط على جهازك، أنشئ حساب المدير واختر **كلمة سر رئيسية قوية واكتبها على ورقة** (لا يمكن استرجاعها).
3. امسح رمز QR بتطبيق Google Authenticator أو Microsoft Authenticator.
4. من **الإدارة ← رابط الدخول** احتفظ بالرابط السري. هذا هو عنوان الموقع لفريقك.

## إضافة عضو

**الإدارة ← الفريق ← دعوة عضو جديد** ← أرسل له الرابط ← يختار كلمة سره ويربط تطبيق المصادقة ← تقارن «البصمة» الظاهرة عنده مع الظاهرة عندك ← **موافقة**.

## قاعدة البيانات والنسخ الاحتياطي

القاعدة على **Neon** (الخطة المجانية لا تنتهي بعد مدة، ومساحتها 0.5 جيجا وتكفي آلاف الحسابات).
رابط الاتصال (`DATABASE_URL`) يُلصق في إعدادات الخدمة على Render فقط، ولا يوضع في الكود أبدًا.

من **الإدارة ← النسخ الاحتياطي** نزّل نسخة مشفرة كل أسبوع أو أسبوعين واحفظها خارج الإنترنت (فلاشة أو درايف خاص)، مع كلمة سرها على ورقة. البرنامج يذكّر المدير إذا مر أكثر من 14 يومًا بدون نسخة.

## تفاصيل البرامج والتجديدات

- لكل حساب جزء اختياري «تفاصيل البرنامج والتجديد»: مكان الاستضافة، مكان قاعدة البيانات، **رابط قاعدة البيانات (مشفر مثل كلمة السر)**، وتاريخ التجديد أو الانتهاء.

## الاشتراكات والفواتير (للمدراء)

من الجرس أعلى الشاشة أو من القائمة ← «الاشتراكات والفواتير»:

- **التنبيهات**: كل دومين وإيميل واستضافة واشتراك وبطاقة دفع وتاريخ مسجّل في الخزنة. تنبيه قبل الموعد بشهرين، ثم قبله بشهر، ثم في الأسبوع الأخير، ثم يوم الاستحقاق. عدد غير المقروء يظهر على الجرس.
- **Hostinger**: كل المواقع (بنوعها وخطتها وموعد تجديدها)، الدومينات، الإيميلات (عدد الصناديق وتاريخ الانتهاء)، كل الاشتراكات وأسعار التجديد، وبطاقات الدفع وتاريخ انتهائها.
- **Render**: كل الخدمات وقواعد البيانات و Key Value، الخطة وسعرها الشهري التقديري، الدومينات المربوطة بكل خدمة، والخدمات الموقوفة.
- **التقرير الشهري**: كل ما يُدفع في الشهر لـ Hostinger و Render وأي تكلفة أخرى تضيفها يدويًا، مع **العميل** و**المبلغ المطلوب منه**، والإجمالي لكل عميل. تنزيل Excel (CSV) أو طباعة / حفظ PDF.
- ربط كل اشتراك بعميله وسعره يُحفظ **مشفرًا بمفتاح الخزنة** في المتصفح (ثم طبقة تشفير ثانية على السيرفر)، ولا يراه إلا المدراء، ويدخل في النسخة الاحتياطية وتغيير المفتاح.
- **الفواتير الرسمية (PDF)**: Hostinger و Render لا يتيحان تنزيلها عبر الـ API، لذلك في كل شاشة رابط مباشر لصفحة الفواتير عند المزوّد.

### الربط

- **Hostinger**: من hPanel بالحساب الذي عليه الدومينات ← API ← API tokens ← New token، وضع المفتاح في Render ← Environment باسم `HOSTINGER_API_TOKEN`.
- **Render**: Account Settings ← API Keys ← Create API Key، وضعه باسم `RENDER_API_KEY`.
- المفاتيح لا تُحفظ في الكود ولا في قاعدة البيانات، والبرنامج يستخدمها بطلبات قراءة (GET) فقط إلى عنوانين ثابتين، ولا تصل للمتصفح أبدًا. البيانات تُجلب كل 30 دقيقة عند الحاجة، أو فورًا بزر «تحديث الآن».

## الطوارئ

- **عضو فقد هاتفه:** الإدارة ← الفريق ← «إعادة ضبط التحقق بخطوتين».
- **جهاز ضاع أو مشبوه:** الإدارة ← الأجهزة ← «حظر الجهاز».
- **وصل رابط الدخول لشخص غريب:** الإدارة ← رابط الدخول ← «تغيير الرابط».
- **المدير الوحيد فقد هاتفه/جهازه:** في Render أضف متغير البيئة `RECOVERY_USER=<اسم المستخدم>`، سجّل الدخول بكلمة السر الرئيسية واربط تطبيق مصادقة جديدًا، ثم **احذف المتغير فورًا**.
- **نسيان كلمة السر الرئيسية:** لا يمكن استرجاعها (هذا ثمن التشفير الكامل). لذلك اجعل في الفريق **مديرَين على الأقل** واحتفظ بنسخة احتياطية.
- **لا تغيّر ولا تحذف `MASTER_SECRET`** في Render أبدًا؛ البرنامج يرفض العمل إذا تغيّر حتى لا تتلف البيانات.

## أمان حساباتكم على المنصات نفسها

البرنامج يحمي كلمات السر المخزنة، لكن أمان الحسابات يكتمل بـ:
فعّلوا التحقق بخطوتين على **Render** و**GitHub** وكل حسابات العملاء نفسها، ولا تحفظوا كلمة السر الرئيسية في المتصفح.

## للمطورين

```bash
npm ci
MASTER_SECRET=$(openssl rand -base64 32) DATABASE_URL=postgres://... node server.js
TEST_DATABASE_URL=postgres://postgres@127.0.0.1:5433/vault_test npm test   # API + تشفير + حسابات الفواتير
./test/run_e2e.sh                                                          # متصفح كامل (Playwright)
```

الملفات: `server.js` (الواجهة البرمجية)، `src/` (الإعدادات، قاعدة البيانات، التشفير على السيرفر)، `public/js/vcrypto.js` (التشفير في المتصفح)، `public/js/app.js` (الواجهة)، `public/js/billing.js` (حسابات التنبيهات والتقرير الشهري)، `src/integrations.js` (القراءة من Hostinger و Render).
